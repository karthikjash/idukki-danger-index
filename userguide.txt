✓ Linux/Mac/Windows with bash or terminal access

    python3 --version
    # Should show: Python 3.9.x or higher

CHECK PIP:
    pip3 --version
    # Should show version information

2. INSTALLATION & SETUP
================================================================================

STEP 1: Navigate to project directory

    cd /home/homie/Projects/SSR_system

    chmod +x quick-start.sh demo.py

    # Allows running scripts directly

6. API REFERENCE & COMMANDS
================================================================================

A. START API SERVER
   ════════════════════════════════════════════════════════════════════════

   python3 api/server.py

   Server runs at: http://localhost:8000


B. GET ALL LOCALITIES
   ════════════════════════════════════════════════════════════════════════

   COMMAND:
       curl http://localhost:8000/localities

   RESPONSE:
       {
         "localities": ["Adimali", "Idukki", "Kattappana", "Kumily", "Munnar", "Nedumkandam", "Peermedu"],
         "count": 7
       }

   WITH FORMATTING:
       curl http://localhost:8000/localities | jq
       curl http://localhost:8000/localities | jq '.localities'


C. GET ALL DANGER INDICES
   ════════════════════════════════════════════════════════════════════════

   COMMAND:
       curl http://localhost:8000/index

   RETURNS:
       Array of objects, each containing:
       - locality: area name
       - tier: 'Low' | 'Moderate' | 'High' | 'Extreme'
       - composite_score: 0-1
       - environmental_severity: 0-1
       - structural_risk: 0-1
       - human_threat_level: 0-1
       - color: hex color code
       - description: plain-language explanation
       - latitude/longitude

   WITH FORMATTING:
       curl http://localhost:8000/index | jq
       curl http://localhost:8000/index | jq '.[] | {locality, tier, composite_score}'

   FILTER BY TIER:
       curl http://localhost:8000/index | jq '.[] | select(.tier == "Extreme")'

   COUNT BY TIER:
       curl http://localhost:8000/index | jq 'group_by(.tier) | map({tier: .[0].tier, count: length})'


D. GET SINGLE LOCALITY INDEX
   ════════════════════════════════════════════════════════════════════════

   COMMAND:
       curl http://localhost:8000/index/Kumily

   REPLACE "Kumily" WITH:
       Adimali, Idukki, Kattappana, Munnar, Nedumkandam, Peermedu

   EXAMPLE - Get Kumily index:
       curl http://localhost:8000/index/Kumily | jq

   GET ONLY TIER:
       curl http://localhost:8000/index/Kumily | jq '.tier'

   GET ONLY SCORE:
       curl http://localhost:8000/index/Kumily | jq '.composite_score'

   GET DESCRIPTION:
       curl http://localhost:8000/index/Kumily | jq '.description'


E. GET HISTORICAL INCIDENTS
   ════════════════════════════════════════════════════════════════════════

   COMMAND:
       curl http://localhost:8000/incidents

   RETURNS:
       Array of incidents with:
       - latitude, longitude (coordinates)
       - incident_type: 'landslide' | 'flood' | 'dam' | 'debris'
       - year: incident year
       - severity: 'low' | 'moderate' | 'high' | 'extreme'
       - location: area name
       - description: details

   FILTER BY TYPE:
       curl http://localhost:8000/incidents | jq '.[] | select(.incident_type == "landslide")'

   FILTER BY YEAR:
       curl http://localhost:8000/incidents | jq '.[] | select(.year >= 2019)'

   FILTER BY SEVERITY:
       curl http://localhost:8000/incidents | jq '.[] | select(.severity == "extreme")'

   COUNT BY TYPE:
       curl http://localhost:8000/incidents | jq 'group_by(.incident_type) | map({type: .[0].incident_type, count: length})'


F. GET INTERACTIVE MAP
   ════════════════════════════════════════════════════════════════════════

   COMMAND:
       curl http://localhost:8000/map > /tmp/map.html

   OPEN IN BROWSER:
       open /tmp/map.html  (macOS)
       xdg-open /tmp/map.html  (Linux)
       start /tmp/map.html  (Windows)

   OR ACCESS DIRECTLY:
       http://localhost:8000/map  (in web browser)


G. GET SUMMARY STATISTICS

from index.map_generator import generate_danger_map
from data.fetcher import fetch_all_data_for_locality, LOCALITIES
from index.calculator import compute_index_for_locality
import pandas as pd

all_indices = {}
all_incidents = pd.DataFrame()

for locality in ['Kumily', 'Peermedu']:
    data = fetch_all_data_for_locality(locality)
    rainfall_df = data['rainfall_forecast']
    current_rainfall = rainfall_df['rainfall_mm'].iloc[-1] if not rainfall_df.empty else 100
    
    weather = {
        'rainfall_mm': current_rainfall,
        'wind_mps': data['wind_data']['wind_speed_mps'],
        'humidity_pct': data['humidity_data']['relative_humidity_pct'],
        'cloud_cover_pct': data['cloud_cover']['cloud_cover_pct']
    }
    
    result = compute_index_for_locality(locality, weather)
    all_indices[locality] = result
    
    if all_incidents.empty:
        all_incidents = data['historical_incidents']

generate_danger_map(all_indices, all_incidents, '/tmp/test_map.html')
print('✓ Map generated at /tmp/test_map.html')
"

8. TROUBLESHOOTING
================================================================================

A. PYTHON NOT FOUND
   ════════════════════════════════════════════════════════════════════════

   ERROR:
       python: command not found

   SOLUTION:
       Use python3 instead of python
       python3 --version

   If python3 also not found:
       • Install Python 3.9+ from python.org
       • Or use package manager: apt-get, brew, etc.


B. DEPENDENCIES NOT INSTALLED
   ════════════════════════════════════════════════════════════════════════

   ERROR:
       ModuleNotFoundError: No module named 'pandas'

   SOLUTION:
       Reinstall dependencies:
       pip3 install -r requirements.txt

   Force reinstall:
       pip3 install --force-reinstall -r requirements.txt


C. PORT ALREADY IN USE
   ════════════════════════════════════════════════════════════════════════

   ERROR (Streamlit):
       Address already in use

   SOLUTION:
       Kill existing process:
       lsof -ti:8501 | xargs kill -9

       Or use different port:
       streamlit run frontend/app.py --server.port=8502

   ERROR (FastAPI):
       Address already in use

   SOLUTION:
       Kill existing process:
       lsof -ti:8000 | xargs kill -9

       Or use different port:
       Edit api/server.py, change port=8000 to port=8001


D. DATA NOT LOADING
   ════════════════════════════════════════════════════════════════════════

   ERROR:
       Error fetching rainfall data

   SOLUTION:
       Check internet connection:
       ping google.com

       Verify data sources are accessible:
       curl https://mausam.imd.gov.in


E. MAP NOT GENERATING
   ════════════════════════════════════════════════════════════════════════

   ERROR:
       Error generating map

   SOLUTION:
       Check if folium is installed:
       python3 -c "import folium; print(folium.__version__)"

       Reinstall:
       pip3 install --force-reinstall folium


F. STREAMLIT NOT RESPONSIVE
   ════════════════════════════════════════════════════════════════════════

   ERROR:
       App doesn't load or is slow

   SOLUTION:
       Clear Streamlit cache:
       rm -rf ~/.streamlit/

       Restart app:
       streamlit run frontend/app.py --logger.level=debug


G. API SERVER NOT RESPONDING
   ════════════════════════════════════════════════════════════════════════

   ERROR:
       Cannot connect to http://localhost:8000

   SOLUTION:
       Check if server is running:
       curl http://localhost:8000/health

       If not running:
       python3 api/server.py

       Check firewall:
       sudo ufw allow 8000  (Linux)


H. PERMISSION DENIED
   ════════════════════════════════════════════════════════════════════════

   ERROR:
       ./quick-start.sh: Permission denied

   SOLUTION:
       Make executable:
       chmod +x quick-start.sh

       Then run:
       ./quick-start.sh

A. ADD A NEW LOCALITY
   ════════════════════════════════════════════════════════════════════════

   STEP 1: Edit data/fetcher.py

   Find this section:
       LOCALITIES = {
           'Kumily': {'lat': 9.655, 'lon': 76.775},
           ...
       }

   Add your location:
       'NewPlace': {'lat': 9.XXX, 'lon': 76.XXX},

   STEP 2: Update population and terrain risk (optional)

   In index/calculator.py, find:
       LOCALITY_POPULATION = { ... }
       TERRAIN_SLOPE_RISK = { ... }

   Add entries for your locality

   STEP 3: Restart the app

   For Streamlit:
       Stop (Ctrl+C) and restart:
       streamlit run frontend/app.py

   For API:
       Stop (Ctrl+C) and restart:
       python3 api/server.py


B. CHANGE DANGER INDEX WEIGHTS
   ════════════════════════════════════════════════════════════════════════

   Edit: index/calculator.py

   Find: calculate_composite_index() method

   Change these values (must sum to 1.0):
       composite_score = (
           0.40 * environmental_severity +  # Change 0.40
           0.35 * structural_risk +         # Change 0.35
           0.25 * human_threat_level        # Change 0.25
       )

   Also adjust thresholds:
       if composite_score < 0.25:
           tier = 'Low'
       elif composite_score < 0.50:
           tier = 'Moderate'
       elif composite_score < 0.75:
           tier = 'High'
       else:
           tier = 'Extreme'


C. CUSTOMIZE TIER COLORS
   ════════════════════════════════════════════════════════════════════════

   Edit: index/calculator.py

   Find: get_tier_color() method

   Change hex colors:
       colors = {
           'Low': '#2ecc71',       # Green
           'Moderate': '#f39c12',  # Orange
           'High': '#e74c3c',      # Red
           'Extreme': '#8b0000'    # Dark red
       }
